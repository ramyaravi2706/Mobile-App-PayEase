## Project Overview

This project focuses on evaluating the usability of the PayEase mobile application using Jakob Nielsen's 10 Usability Heuristics. The main objective is to identify usability issues and provide recommendations to improve the overall user experience.

## Project Objectives

- Evaluate the usability of the PayEase mobile application.
- Identify potential UI/UX issues.
- Analyze the application using Nielsen's 10 usability heuristics.
- Assign severity ratings to identified usability issues.
- Recommend improvements to enhance the user experience.

## Project Scope

The evaluation covers the following four PayEase mobile application screens:

1. Onboarding Screen
2. Home Screen
3. Search Screen
4. Payment Details Screen

## Work Done

- Reviewed the PayEase mobile application screen designs.
- Applied Nielsen's 10 usability heuristics.
- Identified usability strengths and potential issues.
- Assigned severity ratings to the findings.
- Provided recommendations for improving the user experience.
- Prepared a detailed heuristic evaluation report.

## Project Deliverables

- Mobile App Heuristic Evaluation Report
- Evaluation of Nielsen's 10 Usability Heuristics
- Severity Rating Analysis
- UI/UX Improvement Recommendations
- PayEase Application Screenshots

## Evaluation Methodology

The evaluation was conducted using Jakob Nielsen's 10 Usability Heuristics:

1. Visibility of System Status
2. Match Between System and the Real World
3. User Control and Freedom
4. Consistency and Standards
5. Error Prevention
6. Recognition Rather Than Recall
7. Flexibility and Efficiency of Use
8. Aesthetic and Minimalist Design
9. Help Users Recognize, Diagnose, and Recover from Errors
10. Help and Documentation

## Severity Rating Scale

| Severity | Description |
|---|---|
| 0 | No usability problem |
| 1 | Cosmetic issue |
| 2 | Minor usability problem |
| 3 | Major usability problem |
| 4 | Critical usability problem |

## Key Findings and Recommendations

- Improve navigation consistency across screens.
- Provide a payment review and confirmation step before completing transactions.
- Include clear error messages and recovery options.
- Improve text readability where necessary.
- Provide easily accessible Help and Support options.
